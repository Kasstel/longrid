# Блокчейн и туризм

Интерактивный мультимедийный лонгрид о том, как блокчейн может изменить инфраструктуру путешествий: бронирование, платежи, страхование, программы лояльности и работу с данными.

Материал подготовлен на основе реферата Н. В. Лунева, МГТУ «СТАНКИН», 2026. Сайт объясняет принципы технологии, рассматривает реальные проекты и показывает её ограничения.

## Что есть на сайте

- Восемь глав, заключение и ссылки на исследования.
- Переключение эпох Web 1.0, Web 2.0 и Web 3.0.
- Конструктор цепочки блоков с проверкой связей.
- Симулятор страхового условия при задержке рейса.
- Сравнение двух моделей бронирования и расходов.
- Шесть сценариев применения блокчейна в туризме.
- Таймлайн Winding Tree и схема взаимодействия ИИ, IoT и блокчейна.
- Фотографии, видео, аудиофрагмент и текстовые расшифровки.
- Адаптивная верстка, оглавление, прогресс чтения и поддержка уменьшенного движения.

Все учебные сценарии выполняются в браузере. Сервер, регистрация и подключение кошелька не нужны.

## Локальный запуск

Требуется Node.js версии 22.12 или новее и npm.

В терминале откройте папку проекта и выполните:

```sh
npm ci
npm run dev
```

Откройте адрес из терминала, обычно http://127.0.0.1:5173.
Остановить сервер можно сочетанием Ctrl+C.

Если PowerShell блокирует выполнение npm.ps1, используйте `npm.cmd` вместо `npm`.

## Сборка

```sh
npm run build
npm run preview
```

Готовый сайт появляется в папке `dist/`. Предпросмотр обычно доступен по адресу http://127.0.0.1:4173.
Открывайте сайт через HTTP-сервер, а не напрямую через файл index.html.

## Настройка оформления

- `src/styles/tokens.css` — основные цвета и семейства шрифтов.
- `src/styles/fonts.css` — подключение локальных файлов шрифтов.
- `src/styles/globals.css` — сетка, размеры, адаптивность и оформление компонентов.
- `src/content/` — тексты глав и источники.
- `public/media/` — изображения, видео и аудио.
- `public/fonts/` — шрифты.

Основной текст использует Roboto, заголовки — Anticva. Авторы и условия использования медиаматериалов указаны в `public/credits.txt` и доступны по ссылке в разделе источников.

## Проверки

```sh
npm test
npm run test:e2e
```

Unit-тесты проверяют связи блоков, условия страхования и расчёты.
Браузерные тесты проверяют навигацию, интерактивы, медиа и адаптивную верстку. Текущая конфигурация использует установленный Google Chrome на Windows; настройки находятся в `playwright.config.ts`.

## GitHub Pages

В проекте есть workflow `.github/workflows/deploy-pages.yml`.

1. Загрузите содержимое проекта в корень репозитория, в ветку `main`, включая папку `.github`.
2. В настройках репозитория откройте **Settings → Pages → Source** и выберите **GitHub Actions**.
3. Откройте **Actions → Deploy to GitHub Pages**. При необходимости запустите workflow вручную.
4. После завершения публикации адрес сайта появится в настройках Pages.

Дальнейшие изменения в ветке `main` публикуются автоматически. Путь с именем репозитория учитывается при сборке.

Для ручного размещения статических файлов выполните:

```sh
npm run build -- --base ./
```

Размещайте содержимое папки `dist/` целиком.
